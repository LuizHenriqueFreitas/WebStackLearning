Este projeto é a atividade do modulo de Computação em nuvem do curso de Desenvolvimento em .NET da DIO.

No modulo em quetão é apresentado a interface do Microsoft Azure, junto com um breve ensinamento de como usar,
como funcionar e coisas basicas a se fazer, como uso de Azure Functions em aplicações servless. Ou mesmo como
criar e colocar no ar servidores de banco de dados em SQL, ou mesmo NoSQL pra trabalhar com arquivos BLOB.

O que acontece é que azure é pago e eu não estou interessado em aprender isso no momento, sendo assim, no 
exercicio aqui executado eu me foquei apenas no desenvolvimento das APIS propostas, e ainda assim tive dificuldade 
com aquestão do log, mas como o objetivo desse estudo é aprender mais sobre o c# e nao sobre desenvolvimento em 
si, essa questao de log sera estudada a parte em outro momento.
