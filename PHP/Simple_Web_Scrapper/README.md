### Este Projeto

Este simples webScrapper se baseia na finalidade de entender os conceitos de   
o que é um web scrapper, o que isso significa e como isso funciona.

### Funcionamento de um Scrapper

1. PARTE 1   
Basicamente um scrapper se divide em 2 partes, a linguagem que voce estiver   
ulitizando faz uma requisição HTTP para o site desejado e recebe o HTML como   
resposta - essa é a ideia base, mas claro que existem mais coisas nesse caminho,   
como sites com renderização js client-side, etc.

2. PARTE 2   
A segunda parte é apartir do HTML obtido fazer o processamento das informações   
e extrair os dados desejados
